## 5. PIPELINE bugs & fixes found during this test

Two REAL defects found by the first run's FT execution (0/4 PASS), both fixed
and verified (67/67 offline suites):

| # | Symptom | Root cause | Fix | Files |
|---|---|---|---|---|
| 1 | All FT tests without a leading navigate step clicked against `about:blank` → `selector_not_found` | Executor ignored the test's declared `start_page` when step 1 wasn't a navigate | Implicit routing: executor opens `start_page` before steps when needed; logged as `implicit_routing` warning | `fusion/execute_fusion_tests.js` |
| 2 | Catalog selectors like `a:nth-of-type(5)` matched NOTHING live (verified via probe: `querySelector('a:nth-of-type(5)') === null` while 5 anchors exist) | `domExtractor` used the FLATTENED document-wide node index for `nth-of-type()`, which is only valid relative to same-tag siblings under one parent | Correct sibling-relative computation + href-attribute selectors preferred for links (`a[href="…"]`) survive DOM reshuffling | `web/src/domExtractor.js` |

Evidence of defect 2: first-run failures at
`runs/run_20260824_002017/fusion/ft_execution_results.json`
(`selector a:nth-of-type(12) not present`). Pre-fix run kept unmodified.
